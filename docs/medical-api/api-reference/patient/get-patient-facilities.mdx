---
title: "Get Patient Facilities"
description: "Gets all facilities associated with a patient."
api: "GET /medical/v1/patient/{id}/facility"
---

## Path Params

<ParamField path="id" type="string" required>
  The ID of the patient whose facilities are to be returned.
</ParamField>

## Response

<ResponseField name="facilities" type="Facility[]" required>

```javascript Metriport SDK
import { MetriportMedicalApi } from "@metriport/api-sdk";

const metriport = new MetriportMedicalApi("YOUR_API_KEY");

const patientId = "018a80c4-292a-7486-a1234-76yuhe23yu14";
const facilities = await metriport.getPatientFacilities(
  patientId
);
```
