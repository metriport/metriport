# Overview

Suspecting automatically detects potential conditions based on clinical evidence patterns
from patient medical records. The system analyzes clinical data including laboratory results,
medications, procedures, and documented conditions to identify patients who may have undiagnosed
conditions.

Suspecting runs at scheduled intervals and analyzes your patient population to identify potential
conditions that may require clinical review or follow-up.

# Getting Started

Suspecting runs at scheduled intervals and analyzes your patient data to identify potential
conditions. Once suspecting is enabled for your account, results will be available through an API.

# Accessing via API

You can retrieve suspect records using the `GET /medical/v1/suspect` endpoint. Each suspect record
includes a `LAST_RUN` field that identifies the generation/run that produced the suspect,
allowing you to track and filter results by specific analysis runs.

# Accessing via Data Warehouse

Suspect records are also available in the data warehouse under the `DATA_PRODUCTS.SUSPECT` table.
This allows you to query and analyze suspect data using SQL alongside other patient data.

## Table Schema

| Column                          | Description                         |
| ------------------------------- | ----------------------------------- |
| PATIENT_ID                      | The patient identifier              |
| SUSPECT_CONDITION               | The suspected condition             |
| SUSPECT_GROUP                   | Suspect group identifier            |
| SUSPECT_ICD10_CODE              | ICD-10 code                         |
| SUSPECT_ICD10_SHORT_DESCRIPTION | ICD-10 description                  |
| EVIDENCE                        | Supporting clinical evidence (JSON) |
| LAST_RUN                        | Timestamp of last analysis          |

## Example Query

```sql
SELECT * FROM DATA_PRODUCTS.SUSPECT
WHERE SUSPECT_CONDITION like 'Prediabetes%'
AND SUSPECT_GROUP = 'prediabetes_fpg'
ORDER BY LAST_RUN DESC
LIMIT 10;
```

  The `data_source` field in the suspecting evidence follows
