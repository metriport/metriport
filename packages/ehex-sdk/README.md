# `ehex-sdk`

SDK to interact with the
[Ehex FHIR R4 directory](https://ehealthexchange.org/fhir-r4-directory-rollout/) - by Metriport Inc.

## Usage

```
import {
  APIMode,
  EhexManagementApiFhir
} from "@metriport/ehex-sdk";

const api = new EhexManagementApiFhir({
    apiKey: "API_KEY",
    apiMode: APIMode.dev,
});
```
